À propos

WebGIS environnemental

Cette plateforme permet d'explorer les types de végétation, les forêts classées, les parcs nationaux et les limites administratives de la Côte d'Ivoire.

Les données peuvent être consultées directement sur la carte ou dans les tableaux.

À propos du WebGIS

Carte des types de végétation de la Côte d'Ivoire

Cette application cartographique interactive a été conçue à partir de données SIG préparées dans QGIS.

Couches disponibles :
• Types de végétation
• Forêts classées
• Parcs nationaux
• Limites administratives

Outils :
• Recherche géographique
• Localisation
• Mesure des distances et surfaces
• Changement de fond cartographique
• Filtres attributaires
• Tableaux de données
• Export CSV
• Graphiques statistiques

Technologies :
QGIS • qgis2web • Leaflet • JavaScript • Chart.js
